# Attribution

This project builds on the five-stage RV32IM CPU and assembler from
[cepdnaclk/e16-co502-RV32IM-pipeline-implementation-group1](https://github.com/cepdnaclk/e16-co502-RV32IM-pipeline-implementation-group1).

The original project's Git history is retained. Contributor names recorded there
include Buddhi Perera, Shirly Madushanka, shirlyekanayake, Damsy De Silva, and
DamsyDeSilva. Existing author credits in source files are preserved.

The work in this version adds a three-stage Radix-4 Booth multiplier and its CPU
integration, signed/unsigned/mixed multiplication support, regression tests, and
a consolidated demo runner. These additions extend the original implementation;
the original CPU and assembler remain credited to their contributors.
